## UI & Components

Resources for building modern Next.js interfaces.

- [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework.
- [shadcn/ui](https://ui.shadcn.com/) — Reusable React components.
- [Radix UI](https://www.radix-ui.com/) — Accessible UI primitives.
- [Lucide](https://lucide.dev/) — Open-source icon library.

## AI & LLM

Tools for building AI-powered Next.js applications.

- [Vercel AI SDK](https://ai-sdk.dev/) — Toolkit for building AI applications.
- [Google Gemini API](https://ai.google.dev/) — Google's generative AI API.
- [OpenAI API](https://platform.openai.com/) — APIs for building AI applications.
- [Anthropic API](https://www.anthropic.com/api) — Claude API platform.

## Contribution Guidelines

Contributions are welcome.

Before submitting a pull request:

1. Make sure the resource is genuinely useful.
2. Use the correct category.
3. Check that the link works.
4. Avoid duplicate entries.
5. Provide a short, accurate description.
6. Keep the list focused on Next.js and its ecosystem.

Submit changes through a pull request.
